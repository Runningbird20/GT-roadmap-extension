# Bundled Fonts

This directory contains local font files used by the extension font picker. Fonts are bundled so the roadmap page can use them without remote runtime font downloads.

The regular mono TTF Nerd Font files come from the official Nerd Fonts release `v3.4.0`:

https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0

The regular WOFF2 web font files come from Google Fonts CSS API downloads for the requested families.

The readability support WOFF2 files for `OpenDyslexic`, `Lexend`, and `Atkinson Hyperlegible` come from Fontsource packages.

`SF Pro Display` and `Aptos` are offered as local/system font options only. They are not bundled because they are proprietary fonts with redistribution limits.
